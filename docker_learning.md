# Docker Container Technology Learning Record

## Learning Objectives:
1. Understand containerization concepts
2. Master basic Docker commands and operations
3. Learn differences between containers and VMs
4. Practice deploying simple application containers

## Docker Core Concepts:
- **Image**: Application packaging template
- **Container**: Running instance of an image
- **Registry**: Image storage and distribution location
## Practical Applications:
- Microservices architecture deployment
- Development environment standardization
- Continuous Integration/Continuous Deployment (CI/CD)
- Application isolation and resource control

## Common Commands Summary:
- `docker --version` - Check version
- `docker ps` - View running containers
- `docker images` - View local images
- `docker run` - Run container
- `docker stop` - Stop container
